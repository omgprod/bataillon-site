# Bataillon website

Bataillon is a free-to-play freemium mobile game: no account and no ads. This public repository contains only the static marketing, support, and privacy pages. The game source remains private in `omgprod/bataillon`.

- Website: https://omgprod.github.io/bataillon-site/
- Support: https://omgprod.github.io/bataillon-site/assistance/
- Privacy policy: https://omgprod.github.io/bataillon-site/confidentialite/

In the current game version, in-app purchases are not enabled. The site is deployed from `main` using GitHub Pages and GitHub Actions.
