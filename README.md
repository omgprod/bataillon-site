# Bataillon website

Public marketing, assistance and privacy pages for the Bataillon mobile game. This repository contains only the static website; the game source remains in the private `omgprod/bataillon` repository.

- Website: https://omgprod.github.io/bataillon-site/
- Support: https://omgprod.github.io/bataillon-site/assistance/
- Privacy policy: https://omgprod.github.io/bataillon-site/confidentialite/

The site is deployed from the `main` branch using GitHub Pages and GitHub Actions.
